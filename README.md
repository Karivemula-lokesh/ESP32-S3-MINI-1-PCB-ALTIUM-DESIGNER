# 🔌 LOKESH PCB DESIGN — Altium Designer

A printed circuit board (PCB) design project developed using **Altium Designer**. This repository contains the PCB layout, design files, and visual documentation of the completed design.

---

## 📌 Project Overview

This project demonstrates the PCB design workflow, including component placement, copper routing, polygon pours, solder mask configuration, and 3D PCB visualization.

The design was created using Altium Designer to explore professional PCB layout techniques and electronic hardware design.

## 🛠️ Software and Tools

- **PCB Design Software:** Altium Designer
- **PCB Layout:** Component placement and routing
- **Copper Design:** Copper tracks and polygon pours
- **Layer Configuration:** Top and bottom copper and solder mask layers
- **3D Visualization:** PCB inspection and design verification

## ✨ Key Features

- PCB layout design using Altium Designer
- Electronic component placement
- Copper track routing
- Polygon copper pour configuration
- Solder mask layer configuration
- Custom PCB logo design
- 2D PCB layout inspection
- 3D PCB visualization

## 🔍 Design Workflow

1. Created and configured the PCB project in Altium Designer.
2. Placed electronic components on the PCB.
3. Routed copper tracks between component pads.
4. Configured copper layers and polygon pours.
5. Configured solder mask layers.
6. Added a custom PCB logo.
7. Inspected the design using the 2D and 3D views.
